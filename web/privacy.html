Kebijakan privasi

Draf—belum untuk publikasi. Server, identitas/kontak pengelola atau persetujuan konfigurasi rilis belum lengkap. Paket ini tidak mengklaim kebijakan final maupun layanan yang sudah aktif.

Pengelola aplikasi: Belum diisi — perlu identitas pengelola. Kontak permintaan privasi dan bantuan kepemilikan akun: Belum diisi — perlu email kontak pengelola.

Data akun dan keamanan

Untuk membuat akun, XyroPlay menggunakan username dan password. Server menyimpan username, hash password scrypt dengan salt, peran dan waktu pembuatan akun. Server menyimpan hash token sesi dengan masa berlaku satu jam dan hash kode pemulihan. Password, token sesi dan kode pemulihan tidak disimpan sebagai teks biasa di database.

Kode pemulihan ditampilkan sekali dan dapat digunakan mengganti password tanpa email. Setelah digunakan, kode diganti dan semua sesi lama dicabut. Jangan bagikan kode tersebut. Password dan token tidak disimpan di localStorage; token berada di memori aplikasi sampai sesi lokal ditutup.

Profil, foto, riwayat dan file

Nama tampilan, foto profil yang diperkecil dan riwayat penggunaan disimpan lokal pada perangkat. Foto profil tidak diunggah ke server oleh fitur profil. Pemilih dokumen hanya mengakses file yang dipilih pengguna. Hasil gambar/JSON dapat disimpan melalui pemilih lokasi sistem Android; aplikasi tidak memperoleh akses umum ke seluruh penyimpanan.

Fitur online dan penyedia pihak ketiga

Jika dikonfigurasi pengelola, permintaan alat, pencarian, pesan AI, teks dan URL yang dimasukkan dikirim melalui backend ke Synox Cloud (api.synoxcloud.xyz). Hasil media dapat dimuat langsung dari alamat HTTPS pihak ketiga. Server media menerima informasi jaringan seperti IP perangkat saat media dimuat. Jangan memasukkan password, kunci API, kode pemulihan, data kesehatan/keuangan atau informasi rahasia ke fitur alat dan AI.

Penggunaan konten harus sesuai izin pemiliknya dan ketentuan penyedia. XyroPlay tidak menjamin tersedianya semua endpoint penyedia. Pengelola perlu memverifikasi kebijakan, izin pemrosesan serta ketentuan penyedia sebelum mengaktifkannya bagi publik. Aktivasi premium pihak ketiga tidak tersedia.

Tujuan dan retensi

Data akun dipakai untuk autentikasi, kontrol akses, pemulihan dan penghapusan akun; disimpan sampai akun dihapus. Hash sesi yang kedaluwarsa dan pengenal pembatasan permintaan dibersihkan saat operasi pemeliharaan permintaan berikutnya. Pembatasan permintaan memakai pseudonim SHA-256 dari IP/username, bukan menyimpan alamat IP asli pada tabel tersebut; pseudonim tetap dianggap data yang berpotensi terkait pengguna. Bucket pembatasan dipertahankan paling lama satu jam sebelum pembersihan berikutnya.

Log audit keamanan dapat memuat username, jenis tindakan dan waktu; catatan berumur lebih dari 30 hari dihapus pada pemeliharaan berikutnya. Retensi ini tidak menjamin penghapusan tepat pada detik batas bila server tidak menerima permintaan. Server hosting/reverse proxy dapat mempunyai log tersendiri; pengelola wajib membatasi retensinya dan menghapus atau menganonimkan data sesuai kewajiban yang berlaku. Kebijakan backup produksi harus ditetapkan pengelola; backup tidak otomatis dibuat oleh paket ini.

Penghapusan dan kontrol pengguna

Di aplikasi, gunakan menu akun → Hapus akun & data lokal lalu konfirmasi password. Tanpa memasang aplikasi, gunakan halaman penghapusan akun dengan username dan password. Akun, sesi dan hash kode pemulihan di server dihapus setelah autentikasi berhasil. Log keamanan dapat dipertahankan sampai batas retensi di atas untuk penanganan penyalahgunaan.

Profil/riwayat lokal harus dibersihkan di setiap perangkat; penghapusan dari web tidak dapat menghapus file lokal aplikasi di perangkat lain. Tombol Bersihkan profil & riwayat lokal hanya menghapus data perangkat, bukan akun server. Mencopot aplikasi juga tidak menghapus akun server. Untuk password yang terlupa, gunakan pemulihan dengan kode; jika tidak memiliki kode, hubungi pengelola untuk verifikasi kepemilikan tanpa jaminan pemulihan otomatis.

Data yang sudah dikirim ke penyedia pihak ketiga mengikuti kebijakan penyedia dan perlu dikoordinasikan pengelola sesuai kewajiban yang berlaku. Paket source ini tidak memasang SDK iklan atau pelacak analitik; perubahan integrasi di masa depan harus diikuti pembaruan kebijakan dan deklarasi toko.

Hubungi pengelola

Untuk pertanyaan privasi, koreksi, akses atau penghapusan data, gunakan kontak pengelola di atas. Jangan mengirimkan password atau kode pemulihan sebagai bukti kepemilikan.
