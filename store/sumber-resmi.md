# Sumber resmi untuk peninjauan rilis

- [Persyaratan penghapusan akun Google Play](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en-GB): aplikasi yang membuat akun memerlukan alur penghapusan di aplikasi serta tautan web penghapusan; tidak cukup hanya mencopot aplikasi.
- [Penandatanganan aplikasi Android](https://developer.android.com/studio/publish/app-signing): upload key dan Play App Signing berbeda peran; aplikasi yang sudah terbit memerlukan identitas signing yang sesuai.
- [Memuat konten lokal WebView secara aman](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content): penggunaan WebViewAssetLoader untuk aset aplikasi.
- [Deploy Flask di Render](https://render.com/docs/deploy-flask): contoh memakai Gunicorn dan repo source.
- [Persistent disks Render](https://render.com/docs/disks): filesystem biasa bersifat sementara; disk persisten tersedia untuk layanan berbayar. Tidak ada layanan Render dibuat atau tagihan disetujui pada pengerjaan ini.

Referensi ini bukan bukti bahwa server produksi, integrasi API, sertifikat, atau status kebijakan aplikasi pengguna sudah disetujui.
